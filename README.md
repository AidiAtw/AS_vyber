# AS_vyber – airsoft pro začátečníky a výběr zbraně

Jednostránkový mobile-first web (kapitoly 7–9): průvodce výběrem první airsoftové repliky.

- Mobile-first: základní CSS pro mobil, `@media (min-width: 768px)` a `(min-width: 1100px)` mění rozložení (hlavička v řádku, hero ve dvou sloupcích, karty a kroky v mřížce 2 → 3 sloupce).
- Layout: Flexbox (hlavička, hero, výstroj) a CSS Grid (karty, kroky).
- SEO: `title`, `meta description`, jeden `h1`, logické `h2`/`h3`, sémantické `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, popisné `alt`.
- Klíčová slova: airsoft pro začátečníky, airsoftová zbraň / výběr airsoftové zbraně, airsoftová replika, výstroj na airsoft.
- Výkon: obrázky jsou vektorové SVG (celkem pod 3 kB), bez JavaScriptu.
